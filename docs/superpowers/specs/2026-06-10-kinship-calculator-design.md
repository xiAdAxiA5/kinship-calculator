# 亲戚计算器 — 设计文档

> 2026-06-10 | 状态：设计中

## 概述

一个手机 App，帮助用户计算和查询中国亲属称谓。支持正向计算（关系路径 → 称谓）和反向查询（称谓 → 关系路径），覆盖尽可能完整的中国传统亲属关系体系。

## 平台和技术

- **平台**：Android + iOS，使用 React Native (Expo) 一套代码跨平台发布
- **语言**：TypeScript
- **数据**：纯本地，所有称谓规则内置，无需网络即可使用
- **界面语言**：可切换，默认中文

## 核心功能

### 1. 正向计算（路径 → 称谓）

用户告诉我一条关系路径，我算出对应的亲属称谓。

输入示例：「爸爸的哥哥的儿子」→ 输出：「堂兄」

支持两种输入方式：
- **文本输入**：用户直接打字或语音输入一条路径
- **逐步选择器**：从「我」出发，每一步选择一个基本关系（爸爸/妈妈/哥哥/姐姐/弟弟/妹妹/儿子/女儿/丈夫/妻子），逐级往下，直到到达目标亲戚

### 2. 反向查询（称谓 → 路径）

用户输入一个称谓，我解释这个称谓的含义。

输入示例：「堂兄」→ 输出：文字解释 + 关系路径 + 家族位置图谱

支持方式：
- 搜索框直接搜称谓
- 按分类浏览（父系/母系/夫系/妻系 × 长辈/同辈/晚辈）

### 3. 结果展示

- **称谓本身**：大字显示
- **拼音**：方便不认识字的用户
- **文字解释**：用通俗语言解释"谁是谁"
- **关系路径**：从「我」出发的完整路径
- **家族树图谱**：用图展示目标亲戚在家族中的位置

### 4. 语言切换

中/英双语界面，称谓保留中文但附带英文解释。

## 核心引擎设计（图谱遍历）

将整个家族关系建模为一个有向图：

- **节点**：家族成员（虚拟的），每个节点有性别、年龄序（兄/弟/姐/妹）等属性
- **边**：基本关系（父、母、兄、弟、姐、妹、夫、妻、子、女）
- **路径**：从「我」出发沿着边走到目标节点的一条路线

计算过程：
1. 把用户输入的路径解析为图中的边序列
2. 在图中从「我」出发逐条边遍历
3. 到达目标节点后，根据目标节点相对「我」的**辈分差、父系/母系、性别、长幼、直旁系**五个维度
4. 从称谓规则表中匹配最合适的称谓

每个称谓由五个维度唯一决定：
| 维度 | 含义 | 示例取值 |
|------|------|----------|
| 辈分差 | 比我高/低几辈 | +2(祖父)、+1(父)、0(同辈)、-1(子)、-2(孙) |
| 谱系 | 父系/母系/夫系/妻系 | 堂(父系)、表(母系)、外(母系) |
| 性别 | 对方的性别 | 男/女/均可 |
| 长幼 | 对方比我大还是小 | 兄/弟、姐/妹、伯/叔 |
| 直旁系 | 直系还是旁系，旁系代数 | 直系、一代旁系(亲兄弟)、二代旁系(堂兄弟) |

## 界面结构

App 底部三个 Tab：

1. **计算**（正向）：输入路径 → 得出称谓
2. **查询**（反向）：搜索或浏览称谓 → 看解释和图谱  
3. **设置**：语言切换、关于

结果页（从计算或查询进入）展示：
- 顶部：大字称谓 + 拼音
- 中部：文字解释
- 底部：家族树关系图谱

## 数据覆盖计划

目标是尽可能全面覆盖中国传统亲属称谓，包括：

- 直系血亲（父母、祖父母、曾祖父母、子女、孙子女等）
- 父系旁系（伯叔姑、堂兄弟姐妹、再从兄弟姐妹等）
- 母系旁系（舅姨、表兄弟姐妹等）
- 姻亲（配偶、配偶的父母/兄弟姐妹、儿媳/女婿等）
- 宗族关系（族兄弟、族伯叔等）
- 特殊关系（继父母、养父母、干亲等）

## 非功能需求

- 完全离线可用
- 启动速度快（< 2 秒）
- 称谓计算响应 < 100ms
- 界面可点击元素不小于 44x44pt（移动端标准）
- 支持 iOS 和 Android 原生手势
